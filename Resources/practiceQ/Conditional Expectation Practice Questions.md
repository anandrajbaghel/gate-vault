### Conditional Expectation Practice Questions
---
#### Question 1
Given joint probabilities:

- $P(X = 0, Y = 0) = \frac{1}{5}$
- $P(X = 0, Y = 1) = \frac{2}{5}$
- $P(X = 1, Y = 0) = \frac{1}{10}$
- $P(X = 1, Y = 1) = \frac{3}{10}$

Find:
$$E[Y \mid X = 0]$$

**Answer:** $\displaystyle \frac{2}{3}$

---
#### Question 2
Given joint probabilities:

- $P(X = 0, Y = 0) = \frac{1}{6}$
- $P(X = 0, Y = 1) = \frac{1}{3}$
- $P(X = 1, Y = 0) = \frac{1}{4}$
- $P(X = 1, Y = 1) = \frac{1}{4}$

Find:

$$E[Y \mid X = 1]$$

**Answer:** $\displaystyle \frac{1}{2}$

#### Question 4

> Harder: $Y \in \{0,1,2\}$

Given the joint distribution:

| $X$ | $Y$ | $P(X,Y)$ |
|-----|-----|-----------|
| 0   | 0   | $\frac{1}{12}$ |
| 0   | 1   | $\frac{1}{6}$  |
| 0   | 2   | $\frac{1}{4}$  |
| 1   | 0   | $\frac{1}{6}$  |
| 1   | 1   | $\frac{1}{4}$  |
| 1   | 2   | $\frac{1}{12}$ |

Find:
$$E[Y \mid X = 1]$$

**Answer:** $\displaystyle \frac{5}{6}$
